# 🥗 Quomida Website

This repository hosts the public-facing landing page and marketing site for **Quomida**, a mobile-first, privacy-centric macro tracking application.

It is a project of the [Qozara](https://qozara.org) research lab.

## 🚀 Live Links
- **Website:** [https://quomida.qozara.org](https://quomida.qozara.org)
- **Application:** [https://app.quomida.qozara.org](https://app.quomida.qozara.org)
- **Core Repository:** [qozara/quomida](https://github.com/qozara/quomida)

## 🛠 Tech Stack
- **Current:** Single-file static HTML5 & CSS3 (Minimalist, zero-dependency).
- **Future:** Planned migration to [Astro](https://astro.build) for enhanced content management and performance.

## 📂 Structure
- `index.html`: The main landing page.
- `LICENSE`: Apache 2.0 License.
- `/assets`: (Planned) Images, icons, and branding assets.
